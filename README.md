# TranslateForGames
# 🎮 GameTranslator (TranslateForGames)

**GameTranslator** — это полностью локальный голосовой переводчик с русского на английский язык (RU ➡️ EN) со встроенным внутриигровым оверлеем. 

Программа создана для онлайн-игр и кооперативных шутеров: зажми кнопку, скажи фразу по-русски — и на экране поверх игры сразу появится готовый перевод на английский, который можно быстро зачитать тиммейтам в голосовой чат.

---

## ✨ Основные возможности

* **Удобный оверлей поверх игры:** окно с переводом отображается поверх всех окон, **не забирает фокус у игры** и **пропускает клики мыши сквозь себя** (`Click-Through`).
* **Активация по кнопке (Push-to-Talk):** запись идет только пока зажата назначенная клавиша клавиатуры или кнопка мыши (поддерживаются боковые кнопки `X1`/`X2` и колесико).
* **Полностью оффлайн и бесплатно:** распознавание речи (`faster-whisper`) и перевод (`Argos Translate`) работают локально на процессоре (CPU) без использования платных API и облачных сервисов.
* **Поддержка игрового сленга (`glossary.json`):** настраиваемый словарь подсказок и автозамен помогает нейросети правильно понимать геймерские термины (*пушить, респаун, хот зона, эвак, хелс*).
* **Гибкая кастомизация:** настройка размера шрифта, ширины окна, цветов текста и фона, прозрачности, времени показа сообщений и позиции на экране (простым перетаскиванием мыши).
* **Работа в системном трее:** закрытие окна настроек сворачивает программу в трей рядом с часами.

## 🚀 Установка и запуск (Готовая версия)

Для запуска не требуется установленный Python.

1. Перейдите в раздел **[Releases](https://github.com/Tufuteca/TranslateForGames/releases)** и скачайте последний ZIP-архив с программой.
2. Распакуйте архив в любую удобную папку.
   > **Важно:** Не перемещайте и не удаляйте папку `_internal` — она всегда должна находиться в одной папке рядом с `GameTranslator.exe`.
3. Запустите **`GameTranslator.exe`**.

### ⚠️ Важно при первом запуске!
При самом первом запуске программе потребуется интернет, чтобы **один раз** автоматически скачать нейросетевую модель распознавания речи Whisper (`small`) и языковой пакет перевода RU-EN (суммарно около **500–600 МБ**). 
* Пока идет загрузка и подготовка моделей (это может занять от 1 до 3 минут в зависимости от скорости интернета), на экране или в консоли будет написано: `Загружаю модели, подожди...`.
* Дождитесь сообщения **`Готово! Зажми кнопку записи и говори`**. 
* Все последующие запуски будут происходить за пару секунд и работать полностью без интернета.

## ⌨️ Управление по умолчанию

Все клавиши и кнопки мыши можно переназначить в окне настроек программы:

| Действие | Клавиша по умолчанию | Описание |
| :--- | :---: | :--- |
| **Говорить (держать)** | `F9` | Зажмите, произнесите фразу на русском и отпустите для перевода |
| **Перемещение оверлея** | `F8` | Включает/выключает режим перетаскивания оверлея мышью |
| **Показать / скрыть оверлей** | `F7` | Временно скрывает или возвращает оверлей на экран |

## 📖 Настройка игрового словаря (`glossary.json`)

Чтобы переводчик лучше понимал специфичные для вашей игры слова, названия карт, оперативников или сленг, используется файл `glossary.json`. Он состоит из двух секций:

```json
{
  "hints": [
    "хот зона",
    "пушить",
    "прикрой",
    "респаун",
    "эвак",
    "хелс"
  ],
  "replace": {
    "ход зон": "hot zone",
    "хот зон": "hot zone"
  }
}
```

* **`hints` (Подсказки):** слова и фразы, которые передаются модели распознавания речи как контекст, чтобы она чаще выбирала именно их при транскрибации.
* **`replace` (Автозамена):** исправляет частые ошибки распознавания или сразу подставляет нужный английский термин до отправки текста в переводчик.

*Перезапускать программу после редактирования `glossary.json` не нужно — словарь подхватывает изменения автоматически.*

## 🛠️ Запуск из исходного кода и сборка

Если вы хотите запустить проект из исходников или собрать `.exe` самостоятельно (требуется **Python 3.10+**):

1. Клонируйте репозиторий:
   ```bash
   git clone [https://github.com/Tufuteca/TranslateForGames.git](https://github.com/Tufuteca/TranslateForGames.git)
   cd TranslateForGames
   ```
2. Создайте и активируйте виртуальное окружение:
   ```powershell
   python -m venv .venv
   .venv\Scripts\activate
   ```
3. Установите зависимости:
   ```powershell
   pip install PySide6 numpy sounddevice pynput faster-whisper argostranslate pyinstaller
   ```
4. Запустите приложение:
   ```powershell
   python app.py
   ```
5. Для сборки в `.exe` используйте готовый spec-файл:
   ```powershell
   pyinstaller GameTranslator.spec
   ```
   Готовая сборка появится в папке `dist/GameTranslator/`.
